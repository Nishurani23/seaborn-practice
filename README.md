
# Seaborn Practice

This repository contains my **Seaborn practice notebooks and data visualization exercises** while learning Data Science with Python.

Seaborn is a Python visualization library built on top of Matplotlib that helps create informative and attractive statistical visualizations.

## 🎯 Objective

The main objective of this repository is to learn and practice different Seaborn plots and understand how visualization can be used to analyze data.
